How to set up: 
- Create a Python virtual environment (```python -m venv [environment name here]```)
- Activate this virtual environment (platform dependent, check [here](https://docs.python.org/3/tutorial/venv.html) 
- Install packages: ```pip install -r requirements.txt```

Use:
- Run ```Test_Environment.py```
- Check the "experiments" folder for graphs and metrics
